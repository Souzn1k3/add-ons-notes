# Write-back: как создаётся заметка в Samsung Notes

Проблема: у Samsung Notes нет публичного API, а нативный формат файлов
недокументирован (см. `docs/sbn-internals.md`). У сообщества есть ридеры
(twangodev/sdocx и др.), но нет писателей — формулы целостности `<UUID>.page`
в Windows-версии (4.3.x) воспроизвести не удалось.

## Решение: UI-мост (самый безопасный путь)

Агент в интерактивной сессии пользователя:

1. находит окно Samsung Notes (CoreWindow/ApplicationFrameWindow; фильтр по PID
   процесса SamsungNotes.exe — чтобы не спутать с посторонним окном с тем же
   заголовком; свёрнутые окна восстанавливает);
2. временно поднимает окно поверх всех (TOPMOST) — иначе клики попадают в
   перекрывающий браузер, а SetForegroundWindow из фонового процесса Windows
   блокирует; в конце z-order восстанавливается (finally);
3. если открыт редактор — нажимает BackButton, чтобы попасть к списку;
4. кликает мышью по официальной кнопке `CreateNoteButton` («Создать заметку»);
5. ожидает появления `AddPageButton` (открылся новый блокнот);
6. кликает по холсту `SpenComposerViewScrollViewer`, чтобы получить каретку;
7. вводит текст по-символьно через `SendInput` (KEYEVENTF_UNICODE),
   переводы строк — `VK_RETURN`; юникод/эмодзи поддерживаются;
8. нажимает BackButton — приложение само сохраняет заметку в Storage.sqlite/wdoc
   и синхронизирует через Samsung Cloud на все устройства.

Шаги логируются в `%LOCALAPPDATA%\SBNAgent\bridge.log`; ошибки — в `agent.log`.
Жёсткий таймаут на весь мост — 120 секунд, с повторной попыткой на следующем
окне-кандидате (если запущено два экземпляра приложения).

## Почему это безопасно

- агент никогда не пишет в файлы Samsung — всё создаётся собственным UI
  приложения, формат гарантирует сам Samsung Notes;
- хрупкие формулы целостности не воспроизводятся;
- за раз создаётся ровно одна заметка; окно поднимается на время ввода.

## Ограничения

- работает только в интерактивной сессии (в lockscreen — нет);
- приложение должно отвечать: при зависании — таймаут и понятная ошибка;
- текст до 8000 символов (посимвольный ввод);
- заголовок — первая строка текста (приложение само выводит его в заголовок);
- если Samsung Notes запущен в двух экземплярах, агент перебирает окна.

Проверено на реальной машине: заметки с переносами строк и юникодом создаются,
сохраняются в Storage.sqlite и появляются в общем списке; POST /notes/create
возвращает uuid созданной заметки.
