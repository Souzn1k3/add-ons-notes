# Write-back: как создаётся заметка в Samsung Notes

Проблема: у Samsung Notes нет публичного API, а нативный формат файлов
недокументирован (подробности в `docs/sbn-internals.md`). У сообщества есть
ридеры (twangodev/sdocx и др.), но нет писателей — формулы целостности
`<UUID>.page` в Windows-версии (4.3.x) воспроизводить не удалось.

## Решение: UI-мост (самый безопасный путь)

Агент в интерактивной сессии пользователя:

1. находит окно `Windows.UI.Core.CoreWindow` с заголовком «Samsung Notes»
   (если приложение не запущено — запускает через `shell:appsFolder\<AUMID>`);
2. если открыт редактор — нажимает BackButton, чтобы попасть к списку;
3. кликает мышью по официальной кнопке `CreateNoteButton` («Создать заметку»);
4. ожидает появления `AddPageButton` (значит, открылась новая заметка);
5. кликает по холсту `SpenComposerViewScrollViewer`, чтобы получить каретку;
6. вводит текст по-символьно через `SendInput` (KEYEVENTF_UNICODE),
   переводы строк — `VK_RETURN`. Юникод/эмодзи поддерживаются;
7. дальше работает само приложение: автосохранение, запись в
   Storage.sqlite/wdoc и синхронизация Samsung Cloud — все твои устройства
   (включая телефон) получают заметку автоматически.

## Почему это безопасно

- агент никогда не пишет в файлы Samsung — проход через собственный UI
  приложения требует, чтобы формат гарантировал сам Samsung Notes;
- хрупкую формулу целостности не нужно воспроизводить;
- за раз создаётся ровно одна заметка; фокус окна захватывается на время
  ввода (несколько секунд).

## Ограничения

- работает только в интерактивной сессии (в lockscreen — нет);
- текст до 8000 символов (посимвольный ввод);
- заголовок — тоже текст: он пишется первой строкой, и приложение само
  выводит его в заголовок после сохранения (как у заметок с телефона);
- ввод имитирует клавиатуру — если пользователь активно печатает в другом
  окне в тот же момент, фокус перейдёт на Samsung Notes.

Проверено на реальной машине: заметка с переносами строк и юникодом
создаётся, появляется в списке приложения и в Storage.sqlite (автосейв).
