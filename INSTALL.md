# Установка add-ons-notes

Расширение не требует установки из магазина: скачай архив из
[Releases](https://github.com/Souzn1k3/add-ons-notes/releases) и загрузи
папку в браузер. Занимает меньше минуты.

## Шаг 1. Скачай архив

1. Открой страницу релизов:
   https://github.com/Souzn1k3/add-ons-notes/releases
2. У последнего релиза скачай файл `add-ons-notes-v2.0.1.zip`.
3. Распакуй в любое постоянное место, например:
   `C:\Tools\add-ons-notes` — папку потом не удаляй, браузер грузит
   расширение прямо из неё.

Внутри должны лежать `manifest.json`, папки `icons/` и `popup/`.
Если при распаковке появилась вложенная папка — загружай именно ту, где
лежит `manifest.json`.

## Шаг 2. Загрузи в браузер

### Samsung Internet (Windows)

1. В адресной строке открой: `internet://extensions/`
   (или меню «≡» → Add-ons).
2. Включи тумблер **Developer mode** (Режим разработчика).
3. Нажми **Load Unpacked** (Загрузить распакованное).
4. Укажи папку из шага 1 (где `manifest.json`) → **Select Folder**.
5. В списке появится **Заметки** — включи тумблер на карточке.

### Chrome / Edge / Brave / Vivaldi / Opera

1. Открой `chrome://extensions` (в Edge — `edge://extensions`).
2. Включи **Режим разработчика** (Developer mode) справа сверху.
3. Нажми **Загрузить распакованное** (Load unpacked).
4. Выбери папку с `manifest.json`.
5. Закрепи иконку «Заметки» на панели (иконка пазла → булавка).

## Шаг 3. Проверь

Кликни по иконке **Заметки** — откроется попап со списком и приветственной
заметкой. Создай тестовую: «+» → текст → стрелка назад (автосохранение).

## Обновление до новой версии

1. Скачай новый архив из Releases и распакуй **поверх** старой папки
   (замени файлы).
2. Открой страницу расширений браузера и нажми **Update/Обновить**
   на карточке «Заметки» (в Chrome — кнопка «Обновить» на карточке).
3. Заметки не пропадут: они хранятся в профиле браузера, а не в папке.

## Резервная копия и перенос

- **Экспорт**: попап → шестерёнка → «Экспорт заметок (JSON)».
- **Импорт**: тот же экран → «Импорт заметок (JSON)» → выбери файл.
- Импорт объединяет данные: существующие заметки не удаляются, более свежие
  версии с тем же id побеждают.

## Удаление

Удали расширение со страницы расширений браузера (Remove/Удалить) и папку
из шага 1. Заметки хранятся в профиле браузера: до удаления расширения
сделай экспорт JSON, если они нужны.

## Безопасность и приватность

- расширение имеет только разрешение `storage` — никакого доступа к сайтам;
- нет сетевых запросов, серверов и аккаунтов;
- заметки хранятся локально: `chrome.storage.local` в профиле браузера;
- интерфейс в стиле One UI, но проект не связан с Samsung.

## Если что-то не так

- **Иконки нет на панели** — закрепи через меню пазла (или Add-ons в Samsung Internet).
- **Попап открывается вкладкой, а не окном** — особенность конкретной версии
  оболочки Samsung; функциональность та же.
- **Не грузится папка** — убедись, что выбрана папка с `manifest.json`
  на верхнем уровне.
- **Заметки пропали после переустановки** — проверь тот же профиль браузера;
  при сомнениях восстанавливай из экспортированного JSON.
